Projeto de análise de dados com a finalidade de mapear a estrutura da equipe e segmentar colaboradores por idade para apoiar decisões de RH. O projeto utilizou dados via API (dummyjson.com), aplicando conceitos funcionais de Python, limpeza com pandas e estatística com NumPy. Para finalizar, gerou-se um gráfico de departamentos em Matplotlib e aplicou-se o algoritmo KMeans para agrupamento etário automático
